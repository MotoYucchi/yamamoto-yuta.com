# Yamamoto Yuta Portfolio Site

Yamamoto Yuta用のポートフォリオ公開サイトのリポジトリです。

## 概要

このサイトはNode.jsを用いてMarkdownファイルから静的なHTMLサイトをビルドする独自の軽量システムで構築されています。
Magical Mirai風のサイバーで動的でおしゃれなデザインを採用しています。

## ディレクトリ構成

- `src/` : ソースファイルディレクトリ
  - `index.md` : サイトのコンテンツとなるMarkdownファイルです。このファイルを編集して内容を更新します。
  - `template.html` : サイトのベースとなるHTMLレイアウトです。
  - `css/style.css` : サイトのスタイル定義です。
  - `js/main.js` : サイトのアニメーション・動的処理のスクリプトです。
- `public/` : ビルドされた静的ファイルの出力先ディレクトリです。（`.gitignore`で管理から除外されています）
- `build.js` : `src`内のデータを読み込み、`public`ディレクトリに展開するNode.jsビルドスクリプトです。

## 使い方

### 1. 依存ライブラリのインストール
初回のみ以下のコマンドを実行してください。
```bash
npm install
```

### 2. コンテンツの編集
`src/index.md` を編集して、学歴や研究発表などを追加・修正してください。

### 3. サイトのビルド
以下のコマンドを実行すると、`src/index.md`の内容がパースされ、`public/`フォルダにHTMLサイトが出力されます。
```bash
npm run build
```

出力された `public/` フォルダ内のデータを、Webサーバー等にデプロイしてください。
